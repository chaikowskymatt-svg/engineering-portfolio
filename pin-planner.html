1 / Describe the signals

This example uses a GPIO input and output, a DIP switch, a push button, and an LED. The Pin Plan button assigns a unique FPGA pin to each one. Add or change rows to explore.

Automatic planning uses JP2 for GPIO inputs and JP1 for outputs. Custom planning accepts both rows of either header.

Enter an FPGA pin in each row (for example, F13 or PIN_F13), then select Map Custom Pins. Custom GPIO inputs and outputs can use either row of either header. Dedicated input-only pins cannot be outputs; power and ground pins cannot be used as signals. Onboard controls must match their direction.

Connect your signals

3 / Plan the ADALM2000 wires

The GPIO signals get DIO channels in table order; the ground wire is included. For an FPGA input, set the ADALM channel as an output. For an FPGA output, set the ADALM channel as an input. Onboard controls don’t get automatic wires.

GPIO signals are assigned DIO 0–15 in table order. Wire colors follow the supplied ADALM2000 pinout; channels 8–15 have a colored base and white stripe. You can adjust a color to match your cable.

Connect ADALM2000 ground to DE0-Nano ground. Configure each ADALM DIO as an output for FPGA inputs, or as an input for FPGA outputs. Do not drive the same signal from two outputs.

DIP switches, push buttons, and LEDs are onboard components and are not directly accessible on the two GPIO headers. They are not automatically wired to the ADALM2000.
